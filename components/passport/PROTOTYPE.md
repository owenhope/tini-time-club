# Passport UX preview — mock data only

Run `npm run start:dev`, open Profile, then **Preview Martini Passport**.
The development-only route is `/passport-prototype`.

The revised layout follows Golden Glass: a compact introduction, grouped
next-stamp progress, then region cards. Cards open a sample regional page.
The information button explains Passport and contains the empty/sample toggle.
There is one layout, no floating prototype controls, and no simulated search.

Sample progress covers eight venues, three types, and two regions. Nine stamps
derive from the mock tiers, including regional stamps. Recent discoveries are
a short sample, not a complete venue list. Remounting resets the demo.

No backend requests, migrations, persistence, analytics, or real awards.
Both the route and Profile entry are disabled outside development.
Review both themes, larger text, empty state, regional navigation, and scrolling
on a device before promoting the design to production.
