# Marketing site UI kit

The Tini Time Club landing page, composed from this design system.

| File | Section |
|---|---|
| `Hero.jsx` | Deep-green hero — display headline, phone mock, "MAKE IT DIRTY" sticker, avatar proof row |
| `Pillars.jsx` | Purple section with a bento of green / photo / chartreuse tiles + the four product pillars |
| `CommunityProof.jsx` | Real review cards beside a nearby-bars list |
| `DownloadCta.jsx` | Green CTA with the three app-icon colourways, footer and responsible-drinking line |

Nav comes from the system's `SiteHeader`; content data is shared with the app kit (`../mobile_app/data.js`).

**Caveat:** app-store buttons are system `Button`s with icons, not official store badges — swap in the real badges before shipping.
