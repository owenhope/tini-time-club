The pill action button. `primary` for the one main action per view, `onInk` when the surface is brand green.

```jsx
<Button tone="primary" size="lg" icon="martini" block>Rate this tini</Button>
<Button tone="secondary">Save to journal</Button>
```

Tones: primary (green fill), highlight (chartreuse on light), onInk (chartreuse on green), secondary (2px green outline), ghost. Sizes sm/md/lg map to 34/44/54px.
